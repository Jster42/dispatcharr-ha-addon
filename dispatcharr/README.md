# Dispatcharr

Native Home Assistant add-on for [Dispatcharr](https://github.com/Dispatcharr/Dispatcharr), an open-source IPTV and stream management companion.

Access the web UI on port **9191**, with optional Intel/AMD GPU passthrough for transcoding. Data is stored in the add-on persistent directory. Configuration is done in the Home Assistant add-on options.

This build wraps Dispatcharr **0.30.0**.

See **Documentation** on the add-on page for installation, options, hardware acceleration, and NAS storage.
